## The one rule that catches everyone

If the request that starts the flow is not the request that finishes it, `memoryStorage()` will
appear to work in development and fail in production. Serverless functions do not share process
memory, and neither do two instances behind a load balancer.

Use something shared as soon as there is more than one process. That is the whole of
[the storage recipe](/recipes/storage).
