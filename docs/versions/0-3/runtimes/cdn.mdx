description: A self-contained bundle on window.AIOAuth, for pages with no build step.

---

```html
<script src="https://cdn.jsdelivr.net/npm/ai-oauth-sdk/dist/ai-oauth-sdk.global.js"></script>
```

Everything the core and the browser adapter export lands on `window.AIOAuth`. About 13 KB gzipped,
no bundler, no module loader.

<Callout type="warn" title="Bring your own client id here">
  The values in `publicClientIds` will not work from a web origin. They are registered for loopback
  redirects like `http://localhost:1455/auth/callback`, so a provider rejects
  `https://example.com/auth/callback.html` before a consent screen ever appears. Google and
  Microsoft both let you register a web client, which is the way to make the popup flow below work.
</Callout>

## Popup

```html
<button id="signin">Sign in with ChatGPT</button>

<script>
  const client = AIOAuth.createAuthClient({
    provider: 'openai',
    clientId: 'your-client-id',
    redirectUri: 'https://example.com/auth/callback.html',
    storage: AIOAuth.sessionStorageAdapter(),
  })

  document.getElementById('signin').onclick = async () => {
    const tokens = await client.login({ receiver: AIOAuth.popupReceiver() })
    console.log('signed in as', tokens.email)
  }
</script>
```

And at `/auth/callback.html`, one line:

```html
<script src="https://cdn.jsdelivr.net/npm/ai-oauth-sdk/dist/ai-oauth-sdk.global.js"></script>
<script>
  AIOAuth.postCallbackToOpener()
</script>
```

## Redirect

```html
<script>
  const client = AIOAuth.createBrowserAuthClient({ provider: 'openai', clientId })

  AIOAuth.handleRedirectCallback(client).then((tokens) => {
    if (tokens) {
      render(tokens)
    }
  })

  document.getElementById('signin').onclick = () => AIOAuth.startRedirectLogin(client)
</script>
```

## Pinning a version

The unpinned URL follows the latest release. For anything you ship, pin it:

```html
<script src="https://cdn.jsdelivr.net/npm/ai-oauth-sdk@0.3.0/dist/ai-oauth-sdk.global.js"></script>
```

Add Subresource Integrity if the page is worth protecting. jsDelivr publishes the hash for every
file, and a script that handles tokens is exactly the kind you want pinned by content rather than
by name.

## When not to use this

The global build is the browser adapter, so everything on the [Browser](/docs/v/0-3/runtimes/browser) page
applies: same storage caveats, same CORS constraint on the token exchange, same requirement that
the popup opens from a user gesture.

If you already have a bundler, install the package instead. The global build exists for pages that
do not, and it carries both the core and the browser adapter whether you use both or not.
