Install the umbrella package and import from a subpath, or install only the scoped packages you
need. Both are the same code.

```npm
npm install ai-oauth-sdk
```

## Pick your runtime

<Tabs groupId="runtime" persist items={['Terminal', 'Node', 'Browser', 'React', 'React Native', 'Script tag', 'Headless']}>

<Tab value="Terminal">

```npm
npm install -g @ai-oauth-sdk/cli
```

```bash
ai-oauth-sdk login openai
curl -H "Authorization: Bearer $(ai-oauth-sdk token openai)" \
     -H "OpenAI-Beta: responses=experimental" \
     "https://chatgpt.com/backend-api/codex/models?client_version=0.142.5"
```

Not `api.openai.com`: a ChatGPT sign-in opens the subscription surface, not the REST API. The
`client_version` above is a snapshot of `codexClientVersion` in the descriptor, which
`createAuthenticatedFetch` sends for you.

`token` prints the bare token and nothing else, so command substitution stays clean. To keep it out
of your shell history entirely, let the CLI pass it in the environment instead:

```bash
ai-oauth-sdk exec openai -- ./deploy.sh   # arrives as $AI_OAUTH_SDK_TOKEN
```

</Tab>

<Tab value="Node">

```ts
import { login, createNodeAuthClient, publicClientIds } from 'ai-oauth-sdk/node'

// Picks a receiver, opens the browser, catches the callback, and stores the
// tokens in ~/.ai-oauth-sdk/auth.json with mode 0600.
await login('anthropic', { clientId: publicClientIds.anthropic })

const client = createNodeAuthClient({
  provider: 'anthropic',
  clientId: publicClientIds.anthropic,
})

const accessToken = await client.getAccessToken() // refreshes when near expiry
```

`login()` picks the receiver that fits the machine: a loopback server on a desktop, and
paste-the-code over SSH or with no `DISPLAY`, where a loopback redirect could never arrive.

</Tab>

<Tab value="Browser">

```ts
import { loginWithPopup, postCallbackToOpener } from 'ai-oauth-sdk/browser'

button.onclick = () => loginWithPopup('openai', { clientId, redirectUri })
```

On the page at `redirectUri`, call `postCallbackToOpener()` and nothing else. It hands the code
back to the opener and closes the popup.

For embedded webviews and aggressive popup blockers, use the full-page redirect instead:

```ts
import {
  createBrowserAuthClient,
  handleRedirectCallback,
  startRedirectLogin,
} from 'ai-oauth-sdk/browser'

const client = createBrowserAuthClient({ provider: 'openai', clientId })

// Safe to call unconditionally at startup. Returns null when this is not a callback.
const tokens = await handleRedirectCallback(client)

button.onclick = () => startRedirectLogin(client)
```

</Tab>

<Tab value="React">

```tsx
import { useAuth } from 'ai-oauth-sdk/react'
import { popupReceiver } from 'ai-oauth-sdk/browser'

function SignIn() {
  const { login, logout, tokens, isLoading, error } = useAuth({
    provider: 'openai',
    clientId,
    receiver: popupReceiver(),
  })

  if (tokens) {
    return <button onClick={() => logout()}>Sign out</button>
  }

  return (
    <>
      <button onClick={() => login()} disabled={isLoading}>
        Sign in with ChatGPT
      </button>
      {error && <p role="alert">{error.message}</p>}
    </>
  )
}
```

Vue, Svelte and Solid have the same shape. See [Frameworks](/docs/v/0-3/frameworks).

</Tab>

<Tab value="React Native">

```ts
import * as SecureStore from 'expo-secure-store'
import * as WebBrowser from 'expo-web-browser'
import { createAuthClient } from 'ai-oauth-sdk/core'
import { authSessionReceiver, secureStoreAdapter } from 'ai-oauth-sdk/react-native'

const client = createAuthClient({
  provider: 'openai',
  clientId,
  storage: secureStoreAdapter(SecureStore), // Keychain, EncryptedSharedPreferences
})

await client.login({
  receiver: authSessionReceiver({
    webBrowser: WebBrowser,
    redirectUri: 'myapp://auth/callback',
  }),
})
```

Bare React Native uses `deepLinkReceiver({ linking: Linking, redirectUri })` instead. No polyfills
are needed in either case.

</Tab>

<Tab value="Script tag">

<script src="https://cdn.jsdelivr.net/npm/ai-oauth-sdk/dist/ai-oauth-sdk.global.js"></script>

## Name the client id

No provider defaults to one. You pass it, the way you pass a strategy to Passport.

```ts
import { createAuthClient, publicClientIds } from 'ai-oauth-sdk/core'

// The id OpenAI's own Codex CLI publishes.
createAuthClient({ provider: 'openai', clientId: publicClientIds.openai })

// Or one you registered yourself.
createAuthClient({ provider: 'openai', clientId: 'my-registered-client' })
```

<Callout type="warn" title="Using a published id means presenting as that CLI">
  The values in `publicClientIds` are not secrets. They are public PKCE-only clients the vendors
  ship inside their own binaries. Using one means your application identifies itself as that CLI to
  the provider, which is a decision only you can make. Check the provider's terms first, and read
  the [disclaimer](/docs/v/0-3/resources/disclaimer).
</Callout>

Google is the only built-in that also needs a secret, because its installed-app clients do:

```ts
createAuthClient({
  provider: 'google',
  clientId: publicClientIds.google,
  clientSecret: publicClientSecrets.google,
})
```

Full list on the [credentials](/docs/v/0-3/resources/credentials) page.

## Use the token

```ts
await client.getAccessToken() // valid token, refreshed if near expiry
await client.authorizationHeader() // "Bearer sk-ant-oat01-..."
await client.refresh()
await client.logout({ revoke: true })
```

For calling an API, do not read the token once and hold on to it. Hand the SDK a fetch that keeps
itself authenticated:

```ts
import { createAuthenticatedFetch } from 'ai-oauth-sdk/core'

const api = createAuthenticatedFetch(client)
const models = await api('/models').then((response) => response.json())
```

Relative paths resolve against the provider's `apiBaseUrl`, the provider's required headers are
attached, and a 401 triggers one refresh and a replay. See [Using the token](/docs/v/0-3/recipes/ai-sdk).
